# Sablefinch

A local mail client built with React, Vite, and Tailwind CSS. Accounts and messages stay in this browser. There is no server.

## Run

```bash
npm install
npm run dev
```

## Sample inbox

- Email: `mara@sablefinch.test`
- Password: `Sablefinch1`

On the sign-in page, choose **Fill sample account**, then sign in. You can also create a new account or reset a password from the forgot-password page.
